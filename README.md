# Воздушный Шар — фронтенд

Клиент crash-игры «Воздушный Шар». Статическая страница без сборки: HTML, CSS
и JavaScript. Backend: [vozdushnyi-shar-backend](https://github.com/abdulshamilov/vozdushnyi-shar-backend).

## Запуск

1. Поднимите backend (`docker compose up --build` в его репозитории) — он слушает `http://localhost:8080`.
2. Откройте `index.html` через любой статический сервер:

```bash
python -m http.server 5173
# http://localhost:5173
```

Адрес backend меняется без правки кода:

- `?api=https://my-backend.example.com` в адресе страницы — запоминается в браузере;
- ссылка «сменить» внизу страницы;
- значение по умолчанию в `config.js`.

## Что на экране

| Зона | Что делает |
|---|---|
| Лист зондирования | график полёта: границы уровней, след шара, текущий коэффициент |
| Маршрут | зелёная тема (9 уровней) или красная (12) |
| Ставка | четыре варианта из `game-config.yml`, недоступные по балансу выключены |
| Забрать | активна только после первого уровня; пробел — то же самое |
| Коллекция | собранные фрагменты награды, полный набор даёт бонусы |
| Журнал полётов | история завершённых раундов всех игроков или только своих |

## Что клиент не решает

Точку краха, уровень бустера, выплату и очки считает сервер. Клиент опрашивает
`GET /api/rounds/{id}/state` и между ответами плавно экстраполирует
коэффициент по той же экспоненте, но результат раунда всегда берётся из ответа
сервера. Если страницу перезагрузили посреди полёта, повторный запуск
продолжит начатый раунд (сервер отвечает `409 active_round_exists`).
